PNU:LINK — 부산대학교 양산캠퍼스 분실물 / 1차 데모

이 프로그램은 잃어버린 물건을 찾는 연습용 웹페이지입니다.
아래 설명은 Windows 컴퓨터 기준입니다.

1. 먼저 압축을 풀어 주세요
ZIP 파일을 마우스 오른쪽 버튼으로 누르고 ‘모두 압축 풀기’를 선택하세요.
풀린 campus-lost 폴더 안에 app.py와 run.cmd가 함께 있어야 합니다.
압축파일 안에서 바로 실행하거나 run.cmd만 따로 꺼내면 안 됩니다.

2. Python을 설치해 주세요 (처음 한 번만)
Python은 이 프로그램을 움직이게 하는 도구입니다.
Windows 시작 메뉴에서 ‘cmd’를 검색해 ‘명령 프롬프트’를 여세요.
아래 명령을 복사해 붙여넣고 Enter를 누르세요.

winget install --id Python.Python.3.12 --exact --scope user --source winget

설치가 끝나면 CMD 창을 닫으세요. 이미 Python 3.12가 있다면 이 단계는 건너뛰세요.
winget을 찾을 수 없다고 나오면 Microsoft Store에서 ‘앱 설치 관리자’를 설치하거나
https://www.python.org/downloads/windows/ 에서 Python 3.12를 설치하세요.

3. 필요한 도구를 설치해 주세요 (처음 한 번만)
압축을 푼 campus-lost 폴더를 여세요.
폴더 창 위쪽의 주소창을 누르고 cmd를 입력한 뒤 Enter를 누르세요.
열린 CMD 창에 아래 명령을 한 줄씩 입력하고, 각 작업이 끝날 때까지 기다리세요.

py -3.12 -m venv .venv
call .venv\Scripts\activate.bat
python -m pip install -r requirements.txt

이 명령들은 이 앱에 필요한 도구를 담을 폴더를 만들고,
Streamlit, Pandas, Seaborn 등을 한 번에 내려받습니다. 인터넷이 필요합니다.

4. 실행해 보세요
campus-lost 폴더의 run.cmd를 더블클릭하세요. app.py를 누르는 것이 아닙니다!
예시 물건 24건이 자동으로 준비되고 프로그램이 켜집니다.
브라우저가 열리지 않으면 주소창에 http://localhost:8501 을 입력하세요.

명령어로 실행하고 싶다면, 같은 폴더에서 CMD를 열고 아래 한 줄을 입력하세요.
run.cmd

3번 설치 직후의 CMD에서는 아래 명령으로도 실행할 수 있습니다.
python seed_demo.py
streamlit run app.py

다음부터는 설치를 반복하지 말고 run.cmd만 더블클릭하면 됩니다.
종료할 때는 실행 중인 CMD 창에서 Ctrl+C를 누르세요.

5. 이렇게 사용해 보세요
‘물건 찾기’에서 예시 물건을 보거나, ‘주운 물건 등록’에서 새 물건을 올려 보세요.
물건 확인 질문에 답이 맞으면 찾아갈 장소가 나옵니다.
직접 등록한 내역을 다시 보려면 화면에 나온 확인 코드를 따로 적어 두세요.
예시 물건의 등록자 코드는 PNU-DEMO입니다.
혼자 수령 과정을 연습하려면 ‘분실자 역할로 전환’을 누르세요.
상단의 ‘등록자 역할로’와 ‘분실자 역할로’로 오갈 수 있고, 각 역할의 내역은 따로 유지됩니다.
분실 신고 삭제: ‘분실 신고’에서 내 신고 선택 → ‘분실 신고 삭제’ → ‘삭제하기’.

6. 어떻게 만들었나요?
Python의 Streamlit으로 화면을 만들고 Pandas로 물건 정보를 정리했습니다.
종류·색상·특징과 이동한 장소를 비교해 비슷한 물건을 추천합니다.
Folium으로 지도를, Seaborn으로 점수 그래프를 만들었습니다.
첫 화면은 React Bits로 꾸몄고, AI가 물건 확인 답변의 뜻을 비교하게 했습니다.

아직 사진 자체를 비교하지는 않습니다. AI도 틀릴 수 있습니다.
AI 모델은 파일에 들어 있어 별도 API 키가 필요 없습니다. 지도에는 인터넷이 필요합니다.
등록한 내용은 실행한 컴퓨터에 저장되며 다른 사람의 컴퓨터와 자동으로 공유되지 않습니다.

v0.04 - 첫 화면을 두 개의 큰 버튼으로 정리하고 React Bits 배경을 넣었습니다.

v0.07 - 동선과 물건 특징을 점수로 계산하고 Seaborn 그래프로 보여 주게 했습니다.
v0.08 - 실제 AI 답변 비교, 지도 좌표 보정, 예시 24건, 수령 완료 물건 숨기기를 적용했습니다.

v0.10 - 내 분실 신고 삭제 기능을 넣고 그래프를 어두운 화면에 맞게 다듬었습니다.
v0.11 - 공유용 ZIP과 run.cmd를 만들고 예시 자동 준비와 쉬운 실행 안내를 넣었습니다.

v0.13 - 예시 24건에 서로 다른 사진을 넣고 색상과 설명도 다양하게 바꿨습니다.

v0.15 - 분실 신고 후 역할 전환을 고치고 ‘하늘 ↔ 하늘 사진’ 같은 답변 처리를 개선했습니다.

수령번호를 잊었거나 5번 틀렸다면 수령 화면의 ‘수령번호 다시 받기’를 누르세요.

업데이트 전 AI가 자동 승인했던 수령 대기 건은 처음 한 번 답변을 다시 확인합니다.
등록자가 직접 승인한 건과 이미 수령한 기록은 그대로 남습니다.
