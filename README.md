# PNU:LINK

부산대학교 양산캠퍼스 분실물 플랫폼입니다.

## 다른 컴퓨터에서 실행하기

`campus-lost-draft.zip` 전체를 보내고 압축을 해제하세요. `app.py` 하나만 복사하면 시작 화면·사진·다른 Python 모듈이 빠져 실행되지 않습니다. Python 3.12를 권장하며 Node.js는 필요 없습니다. 압축을 푼 `campus-lost` 폴더에서 CMD를 열고 실행합니다.

```cmd
python -m venv .venv
call .venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python seed_demo.py
streamlit run app.py
```

`seed_demo.py`는 빈 DB에 사진과 질문이 포함된 예시 24건을 생성합니다. 기존 데이터가 있으면 신규 예시 20건만 중복 없이 추가합니다. 반환 완료된 예시는 다시 만들지 않습니다. 등록자 코드는 `PNU-DEMO`입니다. 실제 등록물로 시작하려면 이 명령은 생략하세요. DB와 개인 코드·기존 인증 기록은 압축파일에 포함되지 않습니다. 패키지 설치와 배경 지도에는 인터넷 연결이 필요합니다.

`run.cmd`로 실행하면 `seed_demo.py`를 먼저 자동 실행하여 데모 물건을 준비합니다. 예시 없이 시작하려면 위의 `seed_demo.py` 명령을 생략하고 `streamlit run app.py`로 직접 실행하세요.

공유 압축파일에는 로컬 AI 모델도 포함합니다. 모델 가중치 약 118MB와 토크나이저 약 17MB 때문에 압축파일 크기가 커졌습니다. 모델이 포함된 폴더를 받으면 답변 판정은 인터넷/API 키 없이 CPU에서 실행됩니다. 모델을 별도로 전달하지 않은 경우 앱 폴더에서 `python download_model.py`로 고정 모델을 내려받아 복원할 수 있습니다.

**Streamlit + Pandas** 기반 로컬 프로토타입입니다. 등록·검색·추천은 Python에서 처리하고, 첫 화면만 React Bits를 포함한 로컬 React 컴포넌트로 표시합니다. 저장소는 SQLite입니다.

## 실행 (Windows CMD)

Python 3.12에서 검증했습니다. 이 폴더에서 CMD를 열고 필요한 패키지를 설치합니다.

```cmd
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
run.cmd
```

이미 `%USERPROFILE%\.venv`에 환경을 만들었다면 해당 Python으로 `requirements.txt`를 설치한 뒤 `run.cmd`를 실행해도 됩니다. 실행 파일은 앱 폴더로 이동한 다음 테마·보안 설정을 읽어 서버를 시작합니다. 직접 실행할 때도 반드시 앱 폴더에서 `python -m streamlit run app.py`를 실행하세요. 시작 화면은 미리 빌드되어 있어 Node.js 설치가 필요 없습니다.

이전 서버가 실행 중이면 해당 CMD에서 Ctrl+C로 종료하고 `run.cmd`를 실행합니다. 브라우저의 Local URL을 엽니다.

## 화면

- **처음**: React Bits 배경과 ‘분실 신고’, ‘주운 물건 등록’ 두 선택지만 표시합니다.
- **물건 찾기**: 공개 습득물 목록, 종류·색상·키워드 검색, 동선·시간 필터, 지도, CSV 저장.
- **주운 물건 등록**: 사진, 공개 특징, 발견·보관 정보, 선택적인 비공개 소유 확인 특징.
- **분실 신고**: 본인의 신고와 유사한 습득물을 추천합니다. 다른 코드의 신고는 조회할 수 없습니다.
- **내 등록·인증 내역**: 코드 연결, 본인이 등록한 물건, 소유 근거 검토·수령번호 확인, 반환 완료 알림, 자신의 수령 인증 상태.

공식 학교 서비스가 아니며 실제 보관 부서나 LOST112에 연결되지 않습니다.

## 확인 코드

등록 또는 소유 확인 접수 시 `PNU-....` 형식의 **비밀 확인 코드**가 한 번 발급됩니다. 파일로 저장하고 ‘코드를 보관했어요’를 누르세요. 같은 연결 세션에서 만든 내역은 같은 코드에 연결됩니다.

다른 브라우저나 연결 만료 후에는 ‘내 등록·인증 내역 → 확인 코드로 연결’에서 코드를 입력합니다. 새 코드는 대소문자·띄어쓰기·하이픈 차이를 허용합니다. 이전 버전에서 발급한 URL-safe 코드는 호환하지만 대소문자를 구분합니다. 코드 원문은 서버 DB에 저장하지 않습니다. 코드를 잃어버렸을 때 누구나 항목을 가져오는 웹 복구 기능은 제공하지 않습니다.

연결 세션은 1시간 뒤 만료됩니다. ‘내역 연결 해제’를 누르면 서버 세션도 폐기됩니다. 코드는 실명·학교 계정 인증을 대신하지 않으므로 공유하지 마세요.

## 수령 인증과 등록자 알림

v0.12: 반대되는 상태·부정 표현과 수량 차이를 AI 유사도 계산 전에 추가 검사합니다. 문장 유사도만으로 모든 모순을 검출할 수 있는 것은 아니며 판정이 어려운 답변은 등록자가 확인해야 합니다. 수령자가 ‘수령번호 다시 받기’를 누르면 기존 번호를 폐기하고 새 번호를 발급합니다(1시간 3회, 만료 시간 연장 없음). 재발급된 번호는 별도의 입력 시도 횟수를 적용하고, 완료 처리 직전에도 번호가 바뀌지 않았는지 다시 검사합니다.

업데이트 후 첫 실행 시 이전 기준으로 AI가 자동 승인한 수령 대기 건은 한 번만 답변 재확인 상태로 바뀝니다. 등록자가 직접 승인한 건과 반환 완료 기록은 유지합니다. 이미 표시됐던 장소 정보까지 회수할 수는 없습니다.

1. 물건 찾기에서 해당 물건의 **수령 인증**을 누릅니다.
2. 등록자가 정한 구체적인 질문에 답하고 **답변 확인 · 수령 위치 보기**를 누릅니다. 실제 로컬 문장 유사도 AI가 정답과 답변을 비교하며 ‘진한 빨간색 ↔ 빨강’, ‘지퍼가 고장났어요 ↔ 잠금 장치가 잘 안 닫혀요’처럼 다른 표현도 평가합니다. 통과하면 해당 물건 카드 안에 수령 위치를 표시합니다. 1시간 유효한 8자리 수령번호도 발급하지만, 이 단계에서는 물건이 계속 보관 중입니다.
3. 질문/정답이 없거나 답변을 확실히 확인하기 어려우면 수동 확인으로 남깁니다. 등록자가 ‘내 등록·인증 내역’에서 **소유 확인 승인 · 장소 안내**를 누를 수도 있습니다. 공개 목록에는 보관 장소를 제공하지 않으며 반려·기한 만료 시에도 숨깁니다. 대기 중인 답변은 같은 요청에서 다시 입력할 수 있으며 물건별·수령자별 1시간 5회로 제한합니다.
4. 실제 물건을 받은 수령자가 카드 안의 수령 확인을 체크하고 **수령 완료**를 누르면 반환 완료 처리합니다. 같은 세션에서는 저장된 8자리 번호를 사용하고 다른 세션에서는 저장해 둔 번호를 입력해야 합니다. 등록자가 번호와 실제 전달을 확인한 뒤 **확인 후 반환 완료**를 눌러도 됩니다. 미인증·다른 수령자·만료·재사용 번호로는 완료할 수 없습니다. 수령 완료된 물건은 목록·지도·추천에서 제외되고, 다른 브라우저에도 최대 5초 안에 갱신합니다.
5. 반환 완료된 물건은 검색·추천에서 제외됩니다. 등록자의 내역에 수령 시각과 남긴 말이 표시됩니다. 열려 있는 앱은 10초마다 새 소유 확인과 반환 완료 알림을 확인합니다. 앱을 닫아도 기록은 유지됩니다.

등록자와 수령자는 서로 다른 코드 권한으로 처리합니다. 두 브라우저를 쓰거나 아래 역할 전환으로 시연할 수 있습니다. 학생 실명·재학 여부는 확인하지 않습니다. 이메일·문자·외부 푸시도 보내지 않습니다.

등록 시 `소유 확인 질문`과 `질문의 정답 (비공개)`을 함께 입력합니다. 질문에는 정답을 노출하지 마세요. `semantic_ai.py`의 **paraphrase-multilingual-MiniLM-L12-v2 양자화 ONNX 모델**이 원문과 정규화된 답변의 문장 임베딩 유사도를 비교합니다. 통과 기준은 0.80이며 개발용 설정입니다. 색상·모양 등의 상충, 이름/번호 차이, 부정·불확실 표현은 보조 규칙으로 검사합니다. 즉 동의어 목록만으로 통과 여부를 결정하는 방식에서 실제 모델 추론으로 변경했습니다. 점수는 소유 확률이 아닙니다. 모델의 오판정 가능성이 있어 실서비스의 신원 인증을 대신하지 않습니다.

한 브라우저에서 혼자 시연할 때는 본인이 등록한 물건에서 `수령 인증 → 분실자 역할로 전환`을 누르세요. 별도의 짧은 수령자 코드를 발급하고 기존 등록자 연결을 보관합니다. 분실 신고만 등록했거나 확인 코드로 연결한 경우에도 상단의 `등록자 역할로` / `분실자 역할로`로 오갈 수 있습니다. 분실 신고는 분실자 역할, 주운 물건은 등록자 역할로 저장하며 각 역할의 확인 코드와 내역을 유지합니다. 두 역할의 권한은 서버에서 계속 구분하며, 연결 해제 시 저장된 두 세션을 모두 폐기합니다.

## 이전 등록물의 코드가 작동하지 않는 경우

산출물 시연용으로 확인 코드를 단순화했습니다. 빈 DB의 첫 코드는 `PNU-DEMO`, 이후 코드는 `PNU-7K9A`처럼 짧게 발급합니다. 현재 PC의 기존 4건도 `PNU-DEMO`로 연결할 수 있습니다. 다른 코드의 내역까지 공개하는 전체 관리 코드는 아닙니다. 이전의 긴 코드도 계속 사용할 수 있습니다.

이 컴퓨터의 운영자만 아래 도구로 **미연결 항목**을 복구할 수 있습니다. 실행 전 DB를 자동 백업합니다. 이미 코드에 연결된 항목은 재할당하지 않습니다.

```cmd
.venv\Scripts\python.exe recover_registration.py --all-unlinked
```

특정 항목만 연결하려면 `--all-unlinked` 대신 `--item-id 1 --item-id 2`처럼 지정합니다. 새 코드는 `data/private-registration-code-날짜-식별자.txt`에 저장됩니다. 사용자 PC의 기존 4건은 이미 복구했으므로 생성된 파일의 코드를 사용하세요. DB·코드 파일·백업은 비밀 자료이며 소스 압축파일에 포함하지 않습니다.

## 동선 검색·추천

등록한 분실 신고는 **분실 신고 → 내 분실 신고**에서 선택하고 **분실 신고 삭제 → 삭제하기**를 누르면 지울 수 있습니다. **내 등록·인증 내역 → 내 분실 신고**에서도 같은 버튼을 제공합니다. 연결된 확인 코드의 본인 신고만 삭제하며, 주운 물건 등록과 다른 사용자의 신고는 유지합니다. 삭제한 신고는 추천 대상에서 제거됩니다.

그래프는 앱과 같은 어두운 배경에 초록색으로 순위를 강조합니다. 항목별 색상은 각 항목의 최대 배점 대비 비율이며 셀에 실제 점수/배점을 함께 표시합니다. 입력하지 않은 조건은 ‘조건 없음’으로 표시합니다.

동선 검색과 분실 신고 추천에 Seaborn 총점 비교 막대그래프·항목별 점수 히트맵을 표시합니다. 최대 10건을 시각화하고 전체 계산 내역을 표/CSV로 제공합니다. 총점 그래프는 PNG로 저장할 수 있습니다. 종류 최대 40점, 색상·특징·위치 각각 최대 20점이며 입력하지 않은 조건은 최대 배점에서 제외합니다. 예를 들어 동선을 입력하지 않으면 최대 80점입니다. 이 점수는 규칙에 따른 추천 기준이며 소유 확률이나 모델 정확도가 아닙니다.

예시 데이터는 24건이며 각 물건에 서로 다른 생성형 시연 사진을 사용합니다. 지갑·이어폰·우산·후드의 색상과 형태를 다양하게 구성하고 공개 설명과 맞춥니다. 모두 ‘시연용 사진’으로 표시합니다. 색·이니셜·숫자·동물·문양 등 질문과 발견 장소·시간이 다릅니다. 사진·생성 정보는 `assets/demo_photos/`, 추가 데이터 정의는 `assets/demo_items.json`에 있습니다. 기존 예시도 `seed_demo.py` 또는 `run.cmd` 실행 시 사진과 공개 정보를 갱신하며 실제 업로드 사진·개인 등록물·비공개 정답·반환 상태는 유지합니다. 실제 습득 사진이나 성능 평가용 실측 데이터는 아닙니다.

방문 장소를 순서대로 직선 연결하고 각 습득 지점에서 경로 전체까지 최단 거리를 미터 단위 국소 평면 근사로 구합니다. 반경은 50m·100m·200m입니다. 같은 장소를 재방문할 수 있고, ‘없음’은 무시합니다. 전부 ‘없음’이면 전체 검색합니다. 장소 없이 등록한 물건은 일반 검색에는 포함하지만 지도·동선 검색에서는 제외합니다. 지행관(Y16)을 포함합니다.

일반 검색은 선택한 종류·색상과 모든 공백 구분 키워드를 만족해야 합니다. 자동 추천은 종류 일치를 필수로 하고, 선택한 동선 반경을 적용한 뒤 종류 40점·색상 20점·특징 최대 20점·거리 최대 20점으로 정렬합니다. 분실 추정 시작 이후의 습득물을 비교하며 늦게 발견될 수 있어 분실 추정 종료를 습득 상한으로 쓰지 않습니다. 사진은 업로드·저장만 하며 이미지 인식·사진 유사도는 아직 적용하지 않았습니다.

건물명·코드는 [공식 양산캠퍼스맵](https://www.pusan.ac.kr/kor/CMS/Contents/Contents.do?mCode=MN213)과 대조하고 좌표는 **OpenStreetMap 건물 도형의 면적 중심**으로 교체했습니다. 이전 임시 좌표의 큰 오차를 수정했고 기존 등록물의 좌표도 백업 후 같은 장소 기준으로 보정합니다. 경암공학관은 OSM에 건물 도형 대신 부지 도형이 있어 부지 중심입니다. 출입구를 실측한 좌표가 아니며 이동 경로는 아직 직선입니다. 지도 도형·출처·산출 방법은 `assets/campus/`에 보관합니다. © OpenStreetMap contributors, ODbL 1.0.

## 보안과 검증

[SECURITY.md](SECURITY.md)에 OWASP Top 10:2025 기준으로 실제 적용한 방어, 테스트, 운영 전 남은 항목을 기록했습니다. 보안 인증이나 모든 취약점 제거를 의미하지 않습니다. 로컬 실행을 기본으로 하며 실제 서비스로 공개하려면 학교 로그인·TLS·운영 권한·백업·로그·분산 공격 대응을 추가 검증해야 합니다.

```cmd
.venv\Scripts\python.exe -m unittest test_core -v
```

Python 전체 의존성은 `requirements.lock.txt`, React 의존성은 `landing/pnpm-lock.yaml`로 고정합니다. 실행 당시 알려진 취약점 조회 결과는 `security-reports/`에 보관했습니다. 정기적으로 다시 감사하고 업데이트하세요.

React Bits의 출처·고정 커밋·라이선스는 [THIRD_PARTY.md](THIRD_PARTY.md)와 `landing/src/vendor/`에서 확인할 수 있습니다. 소스를 바꾸어 시작 화면을 다시 빌드할 때만 Node.js와 pnpm이 필요합니다.

```cmd
cd landing
pnpm install --frozen-lockfile
pnpm run build
```
